# Read Cameron Reed

![Status](https://img.shields.io/badge/status-active-2ea44f)

An unofficial, spoiler-conscious reader's companion for Cameron Reed's novels, featuring chapter guides, literary analysis, character references, and reading resources.

---

## Features

- Responsive homepage
- Reader's Guide
- Opening chapter companion
- Character pages
- Themes and literary analysis
- Editorial essays and reflections
- Mobile-friendly design

---

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Responsive design
- Git & GitHub
- Static website hosting

---

## Project Goals

Read Cameron Reed is designed to help readers engage more deeply with Cameron Reed's work through thoughtful companion content.

The site complements the reading experience through:

- Chapter-by-chapter reading guides
- Character references
- Literary themes
- Worldbuilding notes
- Reading resources

---

## Running Locally

Clone the repository:

git clone https://github.com/yourusername/read-cameron-reed.git

Open `index.html` in your browser, or serve the project using any static web server.
